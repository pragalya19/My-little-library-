# 📚 My Little Library

Welcome to My Little Library! 🌷

A little corner of the internet dedicated to my love for books.

## ✨ About This Project

My Little Library is my personal book collection, where I can keep track of the books I read, discover new stories, and save my favourite reads.

## 🎀 Features

- 📖 Track books I've read
- ⭐ Save my favourite books
- 📝 Write my reading thoughts
- 🌸 Discover new books

## 💗 Why I Created This

To create a little digital home for all the stories I love.

Made with love for books. 📚✨
